## Inclusion and accuracy policy

- Only public repositories with documentation sufficient to describe the project are included.
- Private repositories and their contents are omitted.
- Public archived repositories may be included when useful, but are not labelled active.
- Prototype limitations stated by a repository are retained in the Vault description.
- Live demo links are only added when documented in the repository or portfolio routes.
- This is a manually reviewed snapshot. Review it when a project's README, public route or maturity changes.
